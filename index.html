FPC = finite population correction √((N−n)/(N−1)). It is exact for sampling without replacement; the AP formula ignores it, which is why we check the 10% condition.

Investigate

  1. Parameter vs. statistic. With the default school (N = 400, 45% girls), identify N, p, n and p̂. Which of these change from sample to sample?
  2. Set n = 25 and press Draw a sample five times. Remember: one dot on the chart = one whole sample's p̂. Describe the sampling variability you see.
  3. Add 1000 samples. How does the mean of the p̂ values compare with p? What does that say about bias?
  4. Trials vs. sample size. Compare n = 25 after 100 samples and after 1000 samples. Then try n = 100. Which one changed the spread: more trials, or a larger n?
  5. Compare the SD of p̂ for n = 25 and n = 100. By what factor did it shrink? Check against σ = √(p(1−p)/n). How large must n be to halve the SD again?
  6. 10% condition. Set n = 100 (25% of the school). Which value is closer to your simulated SD: the theory σ or the FPC σ? Why does the AP formula overstate the spread here?
  7. Population size. Change N to 4000 (same 45%) and use n = 100 again. Did the spread change much? What does this tell you about the role of N vs. n?
  8. Large Counts. Set the school to 10% girls and n = 10. Describe the shape. Increase n until np ≥ 10 and n(1−p) ≥ 10. What happens to the shape?
  9. Evaluate a claim. Someone claims 45% of TNIS students are girls. A random sample of 50 students has only 30% girls. Use the claim tool with n = 50 and P(p̂ ≤ 0.30). Is this convincing evidence against the claim?
  10. Complete the template: “In SRSs of size ___, the sample proportion of girls typically varies by about ___ from the true proportion ___.”
